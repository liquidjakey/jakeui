# Decision journal

**This is a decision trail, not build documentation.** It exists because a retrofit
spans multiple sessions and `design-system.json` only holds machine state — it records
*what* is true, never *why* it was decided.

If you are building a component, you want [`../README.md`](../README.md). Nothing in
here is required reading to write code.

| Directory | Holds |
|---|---|
| `decisions/` | Decision records — the choice, the alternatives, the reason. Dated. |
| `findings/` | What an investigation actually found, including dead ends. |
| `specs/` | A spec for something not yet built. |
| `plans/` | Sequenced work, before it happens. |
| `spikes/` | Throwaway exploration, kept for what it taught. |
| `handoffs/` | State at the end of a session, for whoever picks it up. |

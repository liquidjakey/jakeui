# Jake UI product context

## Register

product

## Users and purpose

Frontend developers, designers and AI agents building product interfaces from a shared React component system. Storybook is an interactive component preview, not an application router. Success means understandable controls and consistent, accessible composition without inventing a different visual system.

## Personality and boundaries

Calm, compact and consistent. Preserve the established product-interface vocabulary and paired light/dark themes. Avoid decorative motion, mismatched icons, novelty controls and marketing-style treatments in task-focused UI.

## Design principles

- Reuse existing components and semantic tokens.
- Give every action clear feedback without leaving a demonstration unexpectedly.
- Distinguish platform-native behavior from application-controlled behavior.
- Keep current contracts discoverable and verify rendered interactions.

## Accessibility and visual authority

Preserve accessible labels, keyboard navigation, visible focus and reduced-motion support. Check narrow layouts and both themes. The existing [design rules](docs/agent/design.md) own visual details; [the workflow](docs/agent/workflow.md) governs extensions and verification.
